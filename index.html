01 — Overview

What is
StringTune?

A cutting-edge JavaScript library for high-performance, modular web effects. Smooth parallax scrolling, dynamic cursor interactions, progress tracking, autoplay videos — all through a powerful, attribute-driven approach that stays intuitive for beginners and advanced developers alike.

07 — Getting Started

Start in
minutes.

Declarative first — most configuration lives right in your markup.

cdn — index.html 
<script src="https://unpkg.com/@fiddle-digital/string-tune@latest/dist/index.js"></script>
terminal 
npm install @fiddle-digital/string-tune
register — app.js 
const stringTune = StringTune.getInstance();
stringTune.use(StringParallax);
stringTune.use(StringMagnetic);
stringTune.start(60); // Start with 60 FPS
markup — the attributes 
<div class="example-container">
  <div class="parallax-item" string="parallax" string-factor="0.8">
    Welcome to StringTune!
  </div>
  <div class="cursor-item" string="magnetic" string-cursor-target="target">
    Hover over me!
  </div>
</div>
